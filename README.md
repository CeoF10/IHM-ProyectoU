# Prototipo IHM — Rehabilitación IESS Guaranda

Frontend académico en React y Vite. Simula registro, solicitud e historial de citas, especialistas, calendario, ejercicios, recordatorios y centros de atención.

## Comandos

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

## Alcance

No incluye backend, autenticación real ni base de datos. Las citas se conservan solo durante la sesión del navegador para demostrar el flujo. Los últimos cuatro números solicitados por el formulario no se almacenan.
